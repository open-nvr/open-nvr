# pyopennvr

Async Python client for the [OpenNVR](https://github.com/open-nvr/open-nvr) API: REST, the event websocket (v2) and WHEP live-view signalling.

It is used by the OpenNVR Home Assistant integration and has no Home Assistant dependency.

Developed in the open-nvr monorepo under `integrations/home-assistant/pyopennvr/` until its first release. See `docs/design/home-assistant-integration.md`.
